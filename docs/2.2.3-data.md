# Dropzone 2.2.3 data and delivery notes

Research date: September 14, 2026. Local-only work; no release or website publication authorized.

## Sensitivity converter

The converter preserves horizontal physical cm/360. It does not match monitor distance, FOV, ADS, scopes, or acceleration. All arithmetic runs locally. No external calculator is embedded or scraped at runtime.

- [Valve's Source SDK input implementation](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/client/in_mouse.cpp) declares default m_yaw 0.022 and multiplies horizontal mouse movement by sensitivity and yaw. This is the implementation reference for the TF2 preset, assuming default yaw, raw input and no acceleration.
- [SensConverter's CS2 to VALORANT documentation](https://sensconverter.app/cs2-to-valorant-sensitivity-converter/) publishes coefficients 0.022 and 0.07, including DPI adjustment. [MouseTester](https://mousetester.io/sensitivity/cs2/) independently lists the same coefficients and the example 2 CS2 -> 0.6286 VALORANT. These two presets are cross-checked converter references, not measurements made in-game by us or a claim that Valve's Source SDK is CS2's current source.
- Formula: cm/360 = 914.4 / (DPI * sensitivity * yaw). Target sensitivity = source DPI * source sensitivity * source yaw / (target DPI * target yaw).
- Measured mode derives a coefficient from the user's measured distance, DPI and sensitivity. It assumes a linear sensitivity scale. A destination measurement must be made at the destination DPI entered. Custom coefficients are user-supplied, not verified by Dropzone.
- Unsupported games have no guessed preset. Select Other game and measure both setups where necessary. Resolution has no role in this physical conversion.

## WARDOGS server status: blocked on authorized data access

The [MetaForge server reference](https://metaforge.app/wardogs/server-status) was identified from MetaForge's actual WARDOGS page. The text fetch exceeded the tool's 4 MB response limit. Its screenshot does not establish a usable API. [MetaForge's terms, section 3](https://metaforge.app/terms) prohibit automated tools without permission. No API/reuse permission was supplied or located, so no runtime scraper was added.

[BattleMetrics' announcement](https://blog.battlemetrics.com/) documents WARDOGS RCON support for server owners. A direct read of `https://api.battlemetrics.com/games` returned HTTP 403: "Access denied. A subscription is required to use the API." Its documentation page also returned a Cloudflare access block. No attempt was made to bypass either. Public WARDOGS coverage could not be verified behind that restriction.

[Warcon's protocol notes](https://github.com/warcon-app/warcon/blob/main/docs/wardogs-api.md) describe an individual server's authenticated RCON status endpoint. This requires an owner-provided server address and administrative bearer token; it is not a public worldwide server directory and does not establish market history access.

Needed: a provider-authorized server directory feed and terms permitting display in Dropzone, plus credentials where required. Verify coverage, region/map/mode fields, classification, timestamps, lock status and allowed refresh cadence before wiring filters/totals. A BattleMetrics subscription alone does not prove all requested fields or worldwide coverage are available.

## WARDOGS gold market: daily public history

User supplied https://wardogshub.gg/gold-market/ and authorized daily factual price extraction. Its inert data-gold-series JSON supplies 532 dated cash-per-bar observations from April 1, 2025 through September 14, 2026 (latest 2,067,814). Only numerical history is reused, with visible source attribution; no page design, article text, or executable scripts are imported.

The backend validates dates, prices and ordering, refreshes once per UTC day while used, coalesces concurrent requests, and retains cached history on errors with a 15-minute retry cooldown. A sourced snapshot supports offline first launch. Older source dates are labeled. History is replaced on refresh because the provider has revised historical prices at Early Access launch. No continuous tick feed or trading execution is claimed.

The interactive chart supports 7D/30D/90D/All, exact-date percentage baselines, range high/low, mouse inspection with a floating price/date tooltip, seven timeline labels, and keyboard navigation directly on the graph. Missing observations are not invented. Server directory integration remains separately blocked as described above.

## Expanded converter catalog

56 working presets are now included. Most use the numeric profile parameters published by Aimlabs' own public converter (retrieved September 14, 2026). Dropzone implements independent forward/inverse arithmetic rather than importing their application code. Presets with offsets or powers retain those terms. The local profile file records each source, scale and relevant input assumptions.

The catalog covers Aimlabs, Apex, ARK Survival Evolved, Battlefield 2042, BattleBit, Battalion, Black Squad, five named Call of Duty versions, Combat Master, Counter-Strike 2/GO, CrossFire/HD, Cyberpunk, DayZ, Deep Rock Galactic, Destiny 2, Diabotical, Dirty Bomb, DOOM Eternal, Dying Light 2, Tarkov, Fortnite, Garry's Mod, Gears 5, GROUND BRANCH, Halo Infinite/MCC, Hell Let Loose, Hunt Showdown, Insurgency Sandstorm, Ironsight, Isonzo, Killing Floor 2, Minecraft Java, Overwatch 2, PAYDAY 2, PlanetSide 2, POLYGON, Quake Champions, Rainbow Six Siege, Rust, SCUM, SCP 5K, Squad, TF2, Titanfall 2, VALORANT, Warface, Warframe and World War Z camera modes.

These are published profiles, not a claim of current-build in-game verification. Certain generic converter pages contradicted Aimlabs or each other (notably THE FINALS, Halo and Marvel Rivals). We did not reuse those generic coefficients indiscriminately. The current THE FINALS profile in Aimlabs differs from another converter, while Mouse-Sensitivity's author reports FOV dependence: https://www.mouse-sensitivity.com/forums/topic/8704-the-finals/ . THE FINALS remains manual. WARDOGS, Marvel Rivals, BO7, current Warzone, Gray Zone Warfare, Battlefield 6 and ARC Raiders are explicitly manual until their current default scales are verified. No automatic support is claimed for those entries. Other games remain available through manual calibration.

The source-game and destination-game pickers are searchable. Fortnite uses percentage units, Minecraft uses its cubic Java slider, Battlefield 2042 includes its nonzero base offset, and R6 assumes the default 0.02 multiplier. Results outside supplied slider limits are rejected. Missing limits are not an assertion of unbounded in-game sliders; round and check the result in the game.

## Live server browser replaces report panel

The user clarified that the requested feature is the actual server directory. The report panel is replaced by a paginated official/community browser sourced from https://wardogservers.com/ . MetaForge's direct request returned a Cloudflare challenge; no bypass was attempted. The alternative publicly renders structured server data and supports server-side search, region, type, map, ruleset, open/locked, empty/full and ordering filters. Only data is parsed with JSON5; website code is never executed. Results are cached 60 seconds per query (bounded to 40 queries), with coalescing, timeout and stale-result fallback. No claim of a stable documented API is made; source format changes may interrupt availability.

All rows are available through 100-row pagination; the UI does not pretend the first page is the entire list. Server codes, reserved slots and favorites are provided. Source map and mode identifiers are preserved; level limits and match start times are unavailable. Current-filter and all-region totals are shown. Coverage comes from the source's observed regions and is not asserted to equal every server in the game.

Live verification passed for available slots/open/community/region filters. Headless Edge checks passed for 100-row rendering, pagination, type and slot filters, favorites, empty search and no page errors. Screenshot: docs/screenshots/server-browser-223.png. Local source/preview only; installer has not been rebuilt for these follow-ups.
