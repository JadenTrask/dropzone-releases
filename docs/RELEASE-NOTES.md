# Dropzone 2.4.8

Game-colored gradients, glass surfaces and soft lighting now carry through the full workspace, navigation, sidebars, controls and dialogs. Shared typography, spacing and responsive layouts keep the app consistent while retaining each game's artwork and identity.

- **Apex Legends:** account-bound player lookup with available current rank, RP, career metrics and per-legend trackers; actual legend imagery, local recent players and favorites. Player, Legends & Meta, News and Esports use the shared top navigation. Dated official balance summaries and source links accompany the roster. Player data comes from Apex Legends Status, an unofficial provider.
- **Gray Zone Warfare:** restores the Lamang tactical map with corrected source protocol and terrain/marker calibration, search and focus, location filters, LZ indicators, pan/zoom, and an inspector that stays beside the map.
- **Rainbow Six Siege:** compact map/side context, a readable round brief grounded in existing guide data, and a five-operator team with real portraits, gadgets and purpose. Operator details remain one click away.
- **THE FINALS:** 85 actual item images replace generic weapon icons across the current weapons, gadgets and specializations. Unknown or unavailable imagery is labeled honestly.
- **Rocket League:** removes the redundant internal sidebar and expands the workspace. Setup & help stays in the header; tracking, account data, profiles, friends and saved matches are preserved.
- **Sons of the Forest:** the full map and sidebar remain intact with consistent search, layers, checkboxes, map controls and attribution.
- **Across Dropzone:** clearer menus, dialogs, state handling and responsive layouts. Home and resume-last-workspace behavior are preserved.

Apex requires a signed-in Dropzone account. Lookup uses an authenticated server-side integration; its provider key is never shipped with the desktop app. Match history, leaderboards and unsupported peak/percentile fields are not invented. The dated balance brief is reviewed editorial context, not a statistical tier list. Existing source freshness warnings remain available.

Validation and limitations are recorded in docs/VALIDATION.md and docs/visual-audit-2.4.8.md. The Windows installer remains unsigned. Native installed-version upgrade, actual gameplay performance, and the complete multi-monitor/controller matrix have not been retested for this release.
