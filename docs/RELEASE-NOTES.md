# Dropzone 2.0

A quieter, more consistent workspace for all your games.

- **Game library:** balanced cards, a centered layout, and a sidebar for switching games. Games in development have their own section.
- **League of Legends:** simpler navigation, clearer build and filter controls, and styling that matches the rest of Dropzone.
- **Sources:** an at-a-glance status overview, filters by game and attention needed, and compact rows that expand for dates, source links, and review preferences.
- **Across the app:** neutral charcoal surfaces, softer accents, and more consistent spacing and typography. Sons of the Forest map controls now leave app text-size shortcuts available.

Your existing tools remain available: League builds and exports, Call of Duty loadouts, THE FINALS class/team loadouts, Siege ranked tools, WARDOGS maps and targets, Sons of the Forest exploration, supported patch feeds, and videos. Existing saved builds, map progress, targets, review preferences, and text settings keep their current formats and app profile.

Gray Zone Warfare remains in development. Its tools and background refreshes are disabled; previously stored local progress is retained. Modern Warfare 4 build support remains coming soon.

This release targets Windows x64. Use the installer or the installed app’s **App updates** page once the release is available. The installer remains unsigned.
