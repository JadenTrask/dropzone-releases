# Dropzone 2.4.1

Fixes practice sessions appearing in Rocket League match history as private matches.

- Private sessions are recorded only after players have been observed on both teams. Ordinary and online Free Play playlist exclusions remain in place.
- One-sided private sessions and empty match entries are excluded from history, statistics, cloud uploads, and post-match recovery.
- Existing affected entries are hidden without deleting saved records. Actual private matches are retained, including matches where opponents leave.
