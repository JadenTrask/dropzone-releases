# Rainbow Six Siege — 1.2.0

Ubisoft supplies the operator catalog, map catalog, official Steam announcements and Designer’s Notes charts. The September 7, 2026 snapshot has 78 operators, 14 maps marked ranked by Ubisoft, and eight charts separating PC/console, attack/defense and presence/ban data. The map catalog is not a verified live rotation feed.

The newest retrieved Designer’s Notes were published August 17 for Y11S3, with charts measuring Y11S2.3 Platinum-and-above play. The current patch announcement is Y11S3. These are distinct dates and patches. Presence is displayed from the official scatter chart; exact live per-map pick/ban rates were not available from a verified source.

Forty ban percentages were transcribed from the official charts. Each table is tied to the exact chart URL. When a new chart arrives, old numeric values are hidden until that chart has been reviewed. The new chart itself is available immediately. Absent percentages mean unavailable, not zero.

Map picks are editorial role-based suggestions, not measured optimal teams. Each map offers attack and defense lineups, role explanations and ban options. Calypso Casino is explicitly a provisional starter lineup. Guides carry their review patch and date.

Catalog/statistics checks and guide checks run on launch and every 15 minutes. Guide feed: https://dropzonecompanion.com/data/siege-ranked.json. Updating that hosted JSON delivers revised guides to existing apps without an installer rebuild. Tactical recommendations still require manual review after balance changes. No automatic analysis of a patch is claimed. Failed requests retain the last valid snapshot and display errors.
