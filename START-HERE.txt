DROPZONE 2.0.0 — WINDOWS x64

INSTALL OR UPDATE
Once the 2.0.0 release is published, run Dropzone-Setup-2.0.0-x64.exe from
https://github.com/JadenTrask/dropzone-releases/releases.
Existing installed copies can receive it through App updates. Portable
copies need the installer once. The installer remains unsigned.

WHAT CHANGED
A balanced game library, a sidebar for switching games, a more consistent
League workspace, and a compact Sources page with game/status filters.
The charcoal interface uses softer accents and clearer spacing throughout.
See docs/RELEASE-NOTES.md for the 2.0 changes.

YOUR EXISTING TOOLS AND SAVES
League, Call of Duty, THE FINALS, Siege, WARDOGS and Sons of the Forest
retain their existing tools. Saved builds, map progress, targets, review
preferences and text settings use the same formats and app profile.
Supported source refreshes, patch notes, videos and exports remain available.

GRAY ZONE WARFARE
Still in development. GZW tools and background refreshes are disabled.
Previously stored local progress is retained. MW4 build support also
remains coming soon.

SOURCE AND DEVELOPMENT
The full source download is Dropzone-Source-2.0.0.zip. Extract it before
opening the project. Use Node.js 24.13.0, then run npm ci and npm start.
Dependencies and generated installers are excluded from the source archive;
app assets, scripts, tests and documentation are included.

RELEASE AND VALIDATION
docs/PUBLISH-RELEASE.md describes the Windows build and draft-release
verification workflow. docs/VALIDATION.md records checks actually completed.
A source ZIP or passing integrity check is not evidence of a completed
native installation, installed upgrade, or in-game accuracy check.
