# Dropzone human target
Continuous MakeHuman base mesh and adult morph targets: CC0 graphical assets.
Source: https://github.com/makehumancommunity/makehuman/tree/master/makehuman/data
See LICENSE.md and the headers in base.obj. No MakeHuman program code is used.

Rendered in Blender 5.2 with scripts/create-damage-body.py; scripts/project-damage-zones.py produces compact SVG hit outlines (requires Shapely).
The diagram is a visual selector, not WARDOGS collision geometry. Damage formulas are unchanged.
